Deep learning research project focused on detecting malicious network traffic using the **Improved CICIDS2017** dataset.

The project investigates deep learning approaches for binary intrusion detection while emphasizing structured evaluation, recall-oriented detection, threshold optimization, and false-negative analysis.

Implemented:

* Network traffic preprocessing and data validation
* Stratified Train / Validation / Test pipeline
* Logistic Regression baseline
* 1D Convolutional Neural Network
* LSTM experimentation
* Threshold tuning
* ROC-AUC evaluation
* Precision-Recall analysis
* Confusion Matrix analysis
* False Negative analysis
* Explainability experimentation

Key CNN evaluation results:

* Weighted F1: **~0.9991**

* Optimized Decision Threshold: **~0.59**
